Recommandation pour le ruban PageMaître
========================================
Utiliser en priorité la version 64 px.
Les versions 48 px et 56 px sont prévues si l'affichage doit être légèrement plus compact.
Les versions 96 px et plus servent aux écrans ou aperçus plus grands.

Les icônes ont été préparées sur fond transparent pour s'intégrer au fond actuel du ruban.
