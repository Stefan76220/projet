# Générateur de Livres

## Présentation

Le Générateur de Livres est une application de bureau développée en Python permettant de créer automatiquement des ouvrages à partir de fiches de données et de modèles de mise en page.

La version 1.0 est dédiée à la réalisation de la collection **Les Graines de Sens**, en particulier la génération d'un livre de fiches sur les plantes alimentaires pour les lapins.

---

## Objectifs de la version 1.0

- Gestion des projets.
- Gestion des documents.
- Gestion des fiches de connaissances.
- Gestion des ressources (images, illustrations, logos…).
- Gestion des modèles de pages.
- Génération automatique des fiches.
- Génération automatique des annexes.
- Construction du livre.
- Export PDF prêt pour l'impression.

---

## Architecture

Le projet est organisé autour de plusieurs composants indépendants :

- Application
- Gestionnaire de projets
- Gestionnaire de documents
- Moteur de génération
- Bibliothèque documentaire
- Gestionnaire des ressources
- Interface graphique
- Moteur de rendu
- Système de commandes
- Outils d'édition

Cette architecture a été pensée pour permettre l'évolution future vers un véritable logiciel de publication assistée par ordinateur.

---

## Version 2.0 (prévue)

La version 2.0 ajoutera notamment :

- Composition automatique de texte libre.
- Import DOCX, Markdown et TXT.
- Gestion avancée des styles.
- Gabarits éditoriaux.
- Mise en page intelligente de livres complets.
